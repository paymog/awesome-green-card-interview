# Contributing

Thank you for helping couples prepare. Please follow these rules.

## What belongs on the list

- The resource helps with a marriage-based green card (adjustment of status) case or interview at a USCIS field office.
- It is free to use, or it is clearly useful enough to list as paid.
- It works today. Check the link before you send it.
- It does not promise an approval, a faster case, or a "guaranteed" result.

## How to add or change an entry

1. Open a pull request that edits `README.md`, or open an issue if you prefer.
2. Put the entry in the right section.
3. Use this format, on one line:

   ```
   - [Name](https://example.com) - What it is good for, in one or two plain sentences.
   ```

4. Start the description with `Paid.` if the resource charges money.
5. Say in the pull request why the resource helps, and whether you work for it.

The maintained copy of this list is at [readyformyinterview.com/resources](https://readyformyinterview.com/resources). The maintainer copies accepted changes there, and the README is generated from that page.

## What we do not accept

- Affiliate links or tracking parameters.
- Paid placements or link swaps.
- Legal advice in a description.
- Duplicate entries.
